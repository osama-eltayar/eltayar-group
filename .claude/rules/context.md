# Project Context

This is a Laravel 11 application.

## Key Features
- Admin dashboard is fully powered by Laravel Nova.
- API routes are defined in `routes/api.php` and are versioned.
- Localization support is enabled (Arabic + English).
- Uses Eloquent ORM with strict typing and policies.

## Tech Stack
- PHP 8.3
- Laravel 11
- Laravel Nova 4.x
- MySQL
